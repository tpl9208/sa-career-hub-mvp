# SA Career Hub — MVP

A simple mobile-first South African opportunities website for learnerships, internships, graduate programmes and entry-level jobs.

## Run it
Open `index.html` in a browser. No framework or build step is required.

## Files
- index.html — page structure
- style.css — responsive design
- script.js — sample opportunity data, search and filters

## Before publishing
1. Replace the sample opportunities in `script.js` with real listings.
2. Make each `url` point to the employer's official application page.
3. Add About, Contact, Privacy Policy and Terms pages.
4. Add Google AdSense only after the site has useful original content and meets Google's current publisher policies.
5. Add a clear "last verified" date to each listing.
6. Never charge applicants to access a legitimate listing and never copy misleading/fraudulent job adverts.
